# .env.dist (configuration)

**Chemin :** `.env.dist`
**Configure :** `Environnement de test automatisé (Codeception)`
**Dernière mise à jour doc :** 2026-05-28

---

## Ce que ce fichier configure
Template du fichier `.env.test` utilisé par la suite de tests automatisés Codeception. Définit les paramètres de connexion à la base de données de test, l'URL de l'instance SuiteCRM testée, et les paramètres du navigateur automatisé (Selenium/Webdriver).

## Paramètres clés

| Paramètre | Valeur exemple | Effet |
|---|---|---|
| `DATABASE_DRIVER` | `MYSQL` | Type de base de données (`MYSQL` ou `MSSQL`) |
| `DATABASE_HOST` | `localhost` | Hôte du serveur de base de données de test |
| `DATABASE_NAME` | `automated_tests` | Nom de la base de données de test |
| `DATABASE_USER` | `automated_tests` | Utilisateur DB de test |
| `DATABASE_PASSWORD` | `automated_tests` | Mot de passe DB de test |
| `INSTANCE_URL` | `http://localhost:8000` | URL de l'instance SuiteCRM testée |
| `INSTANCE_ADMIN_USER` | `admin` | Identifiant admin de l'instance |
| `INSTANCE_ADMIN_PASSWORD` | `password` | Mot de passe admin |
| `INSTANCE_CLIENT_ID` | `suitecrm_client` | ID client OAuth2 pour les tests API |
| `INSTANCE_CLIENT_SECRET` | `secret` | Secret client OAuth2 |
| `BROWSER` | `chrome` | Navigateur pour les tests acceptance |
| `WEBDRIVER_HOST` | `127.0.0.1` | Hôte Selenium/Webdriver |
| `WEBDRIVER_PORT` | `4444` | Port Selenium/Webdriver |

## Impacté par / impacte
- Doit être copié en `.env.test` et rempli avant de lancer les tests Codeception
- Consommé par `codeception.dist.yml` (section `params: - .env.test`)
- Référencé dans la documentation officielle : `https://docs.suitecrm.com/developer/automatedtesting/`

## Notes techniques
- Ce fichier ne contient aucune valeur secrète réelle — c'est un template avec des valeurs d'exemple.
- `.env.test` (le fichier réel) ne doit jamais être commité en version control.
