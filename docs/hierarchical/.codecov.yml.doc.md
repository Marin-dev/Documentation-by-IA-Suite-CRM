# .codecov.yml (configuration)

**Chemin :** `.codecov.yml`
**Configure :** `Codecov — service de couverture de code`
**Dernière mise à jour doc :** 2026-05-28

---

## Ce que ce fichier configure
Paramètre le comportement du service Codecov lors de l'analyse des rapports de couverture de code générés par les tests Codeception/PHPUnit. Définit les seuils, la précision d'affichage et les répertoires exclus de l'analyse.

## Paramètres clés

| Paramètre | Valeur | Effet |
|---|---|---|
| `codecov.notify.require_ci_to_pass` | `yes` | N'envoie pas de notification Codecov si le CI a échoué |
| `coverage.precision` | `2` | Affichage de la couverture avec 2 décimales |
| `coverage.round` | `down` | Arrondi par défaut vers le bas |
| `coverage.range` | `70...100` | Plage de couverture attendue (vert entre 70% et 100%) |
| `status.project.default.target` | `0%` | Cible minimale de couverture du projet (0% = pas de blocage) |
| `status.project.default.threshold` | `5%` | Tolérance de baisse de couverture acceptée |
| `status.patch` | `no` | Pas de vérification de couverture sur les patches |
| `status.changes` | `no` | Pas de vérification sur les fichiers modifiés |
| `comment.layout` | `header, diff` | Format du commentaire PR Codecov |

**Répertoires ignorés :**
- `include/timezone/*`, `include/SuiteGraphs/*`, `include/social/*`, `include/Smarty/*`, `include/reCaptcha/*`, `include/phpmailer/*`, `include/Pear/*`, `include/pclzip/*`, `include/nusoap/*`, `include/HTTP_WebDAV_Server/*`, `include/HTMLPurifier/*`, `include/ytree/*`
- `modules/AOS_PDF_Templates/PDF_Lib/*`, `modules/AOD_Index/Lib/*`, `modules/Users/authentication/SAML2Authenticate/lib/*`, `modules/AOR_Charts/lib/*`
- `Zend/*`, `install/demoData.en_us.php`, `include/tcpdf/*`
- `lib/API/*` (ancienne API V8 lowercase, dépréciée)

## Impacté par / impacte
- Consommé par Codecov après que `.travis.yml` envoie `coverage.xml`
- Les exclusions correspondent aux bibliothèques tierces intégrées directement dans le dépôt

## Notes techniques
- La cible de couverture à `0%` indique que le seuil de couverture n'est pas encore utilisé comme bloquant CI.
- Les exclusions de `lib/API/*` confirment que l'ancienne API lowercase V8 est abandonnée.
