# .travis.yml (configuration)

**Chemin :** `.travis.yml`
**Configure :** `Pipeline CI/CD Travis CI`
**Dernière mise à jour doc :** 2026-05-28

---

## Ce que ce fichier configure
Définit le pipeline d'intégration continue sur Travis CI pour SuiteCRM. Orchestre trois jobs parallèles : tests fonctionnels PHP 7.4/MySQL, validation Composer, et génération de couverture de code.

## Paramètres clés

| Paramètre | Valeur | Effet |
|---|---|---|
| `language` | `php` | Runner PHP |
| `matrix.include[0]` | PHP 7.4 / MySQL 5.7 | Job principal de tests |
| `matrix.include[1]` | composer validate | Vérification cohérence composer.json/lock |
| `matrix.include[2]` | code coverage | Génération et envoi coverage vers Codecov |
| `services` | mysql, elasticsearch | Services requis pour les tests |
| `addons.chrome` | stable | Chrome pour les tests acceptance |
| `branches.only` | master, develop, hotfix/*, feature/*, fix/*, staging/* | Branches déclenchant le CI |

**Variables d'environnement injectées :**
- `INSTANCE_URL`, `DATABASE_DRIVER`, `DATABASE_NAME`, `DATABASE_HOST`, `DATABASE_USER`, `DATABASE_PASSWORD`, `INSTANCE_ADMIN_USER`, `INSTANCE_ADMIN_PASSWORD`, `COMPOSER_MEMORY_LIMIT=-1`

**Séquence d'exécution :**
1. `before_install` : installation ChromeDriver, lint PHP des fichiers modifiés
2. `install` : config PHP, `composer install`, `codecept build`
3. `before_script` : création DB MySQL, installation Apache + PHP-FPM, configuration vhosts
4. `script` : installation wizard Codeception, PHPUnit, tests API V8, tests acceptance
5. `after_script` : publication des outputs, logs Apache et ElasticSearch

## Impacté par / impacte
- Déclenché sur push/PR vers les branches listées
- Dépend de `codeception.dist.yml` pour la configuration des tests
- Utilise `build/travis-ci-apache` pour la config Apache
- Envoie la couverture vers Codecov (configuré par `.codecov.yml`)

## Notes techniques
- Ce fichier cible PHP 7.4 alors que `composer.json` et `php_version.php` exigent PHP >= 8.1 — incohérence probable due à un fichier non mis à jour depuis la migration vers PHP 8.
- Le ChromeDriver est fixé à la version 2.36 (ancienne) — risque de rupture avec les versions récentes de Chrome.
- `COMPOSER_MEMORY_LIMIT=-1` désactive la limite mémoire Composer pour éviter les OOM sur les gros dépôts.
