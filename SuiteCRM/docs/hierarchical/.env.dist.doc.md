# .env.dist (configuration)

**Chemin :** `.env.dist`
**Configure :** `Environnement de test automatisé (Codeception)`
**Dernière mise à jour doc :** 2026-05-30

## Rôle

Fichier template de variables d'environnement destiné aux suites de tests automatisés. Il doit être copié en `.env.test` et adapté à l'environnement local. Ne produit aucun effet s'il n'est pas renommé.

**Type :** config

## Ce que ce fichier configure

Fournit les valeurs par défaut pour connecter les tests automatisés à une base de données dédiée, à une instance SuiteCRM en cours d'exécution, et à un service WebDriver (Selenium). Il isole l'environnement de test de celui de développement.

## Paramètres clés

| Paramètre | Valeur par défaut | Effet |
|---|---|---|
| `DATABASE_DRIVER` | `MYSQL` | Pilote de base de données (MYSQL ou MSSQL) |
| `DATABASE_HOST` | `localhost` | Hôte du serveur de base de données |
| `DATABASE_NAME` | `automated_tests` | Nom de la base dédiée aux tests |
| `DATABASE_USER` | `automated_tests` | Utilisateur de la base de tests |
| `DATABASE_PASSWORD` | `automated_tests` | Mot de passe de la base de tests |
| `INSTANCE_URL` | `http://localhost:8000` | URL de l'instance SuiteCRM testée |
| `INSTANCE_ADMIN_USER` | `admin` | Compte admin pour les tests d'acceptance |
| `INSTANCE_ADMIN_PASSWORD` | `password` | Mot de passe admin pour les tests |
| `INSTANCE_CLIENT_ID` | `suitecrm_client` | ID client OAuth2 pour les tests API |
| `INSTANCE_CLIENT_SECRET` | `secret` | Secret client OAuth2 pour les tests API |
| `BROWSER` | `chrome` | Navigateur utilisé pour les tests d'acceptance |
| `WEBDRIVER_HOST` | `127.0.0.1` | Hôte du WebDriver (Selenium) |
| `WEBDRIVER_PORT` | `4444` | Port du WebDriver |

## Impacté par / impacte

- Consommé par `codeception.dist.yml` (section `params: env, .env.test`)
- Utilisé par les suites Codeception : Install, Acceptance, API
- Variables injectées dans les tests via la bibliothèque `vlucas/phpdotenv`

## Points d'attention

- Ce fichier ne doit **jamais** être commité avec des mots de passe réels ; c'est un template.
- Le fichier effectif à créer s'appelle `.env.test` (non versionné).
- Les mots de passe par défaut (`password`, `secret`, `automated_tests`) sont délibérément faibles — à changer avant tout usage.
- La documentation officielle est disponible sur `https://docs.suitecrm.com/developer/automatedtesting/`.
