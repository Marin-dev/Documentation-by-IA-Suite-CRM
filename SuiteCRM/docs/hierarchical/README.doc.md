- Ce README décrit SuiteCRM 7 — SuiteCRM 8 est une réécriture séparée (`SuiteCRM-Core`) avec une architecture différente.
- La mention de la démo publique signale qu'elle se reconstruit toutes les heures — ne pas y uploader de données personnelles.
