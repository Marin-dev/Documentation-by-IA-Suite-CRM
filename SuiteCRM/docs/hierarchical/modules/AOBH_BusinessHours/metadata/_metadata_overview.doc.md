# Metadata du module AOBH_BusinessHours

**Chemin :** `modules/AOBH_BusinessHours/metadata/`
**Type :** PHP — configuration (metadata SugarCRM)
**Derniere mise a jour doc :** 2026-06-02

---

## Contenu du dossier
Tous les fichiers de ce dossier sont des fichiers de configuration pure (tableaux PHP) utilises par le framework SugarCRM pour definir les vues et comportements du module AOBH_BusinessHours.

| Fichier | Role |
|---|---|
| `SearchFields.php` | Champs de recherche basique et avancee |
| `dashletviewdefs.php` | Configuration de la vue dashlet |
| `detailviewdefs.php` | Layout de la vue detail |
| `editviewdefs.php` | Layout du formulaire d'edition |
| `listviewdefs.php` | Colonnes de la vue liste |
| `metafiles.php` | Liste des fichiers metadata a charger |
| `popupdefs.php` | Configuration du popup de selection |
| `quickcreatedefs.php` | Layout du formulaire de creation rapide |
| `searchdefs.php` | Definition des filtres de recherche |
| `subpanels/default.php` | Configuration du sous-panneau par defaut |

## Points d'attention
- Tous ces fichiers sont de la configuration pure — pas de logique metier.
- Les modifications doivent se faire via Studio ou dans `custom/Extension/modules/AOBH_BusinessHours/Ext/`.
