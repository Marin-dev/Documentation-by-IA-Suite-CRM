# subpaneldefs.php (configuration)

**Chemin :** `modules/Bugs/metadata/subpaneldefs.php`
**Configure :** Sous-panneaux de la vue detail d'un bug
**Derniere mise a jour doc :** 2026-05-31

## Ce que ce fichier configure
Definit quels sous-panneaux (Contacts, Comptes, Cases, Activites, Emails...) sont affiches sur la vue detail d'un bug et comment ils sont configures.

## Impacte par / impacte
- Consomme par le framework SuiteCRM lors du rendu de la vue detail (action=DetailView)

## Notes
- Fichier purement declaratif.
