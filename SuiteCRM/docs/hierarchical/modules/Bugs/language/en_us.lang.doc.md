**Derniere mise a jour doc :** 2026-05-31

## Ce que ce fichier configure
Definit les chaines de traduction anglaises (`$mod_strings`) pour les labels, titres et messages du module Bugs.

## Impacte par / impacte
- Charge par le framework SuiteCRM via `return_module_language('en_us', 'Bugs')`
- Utilise par toutes les vues et le modele Bug
