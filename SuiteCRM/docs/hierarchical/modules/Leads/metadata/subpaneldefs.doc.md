# Fichier : subpaneldefs.php

**Chemin :** `modules/Leads/metadata/subpaneldefs.php`
**Type :** `PHP`
**Categorie :** configuration (sous-panneaux)
**Derniere mise a jour doc :** 2026-05-31

---

## Ce que ce fichier configure

Definit les sous-panneaux affiches dans la vue detail du module Leads (history, calls, meetings, tasks, FP_events, etc.).

---

## Parametres cles

| Sous-panneau | Module lie |
| --- | --- |
| history | Emails/Notes/Appels/Reunions lies |
| calls | Calls |
| meetings | Meetings |
| tasks | Tasks |
| fp_events_leads_1 | FP_Events |

## Points d'attention

- Fichier de configuration pur. Les leads n'ont pas de sous-panneaux pour cases/opportunities (ils n'ont que des liens apres conversion).
