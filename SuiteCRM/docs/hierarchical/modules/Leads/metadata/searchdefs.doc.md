## Ce que ce fichier configure

Definit les panneaux de recherche basique et avancee du module Leads via `$searchdefs['Leads']`.

---

## Parametres cles

| Parametre | Effet |
| --- | --- |
| `basic_search` | Nom, email, telephone, status, assigned_user |
| `advanced_search` | Tous les criteres disponibles (lead_source, campagne, adresse, etc.) |
