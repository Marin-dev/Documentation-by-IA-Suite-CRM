## 🎯 Responsabilité fonctionnelle
Le module SurveyQuestionOptions gère les options de réponse pour les questions de sondage à choix multiples. Chaque option représente une réponse possible à une question.

## ⚙️ Responsabilité technique
Bean généré par Module Builder. Module simple.
