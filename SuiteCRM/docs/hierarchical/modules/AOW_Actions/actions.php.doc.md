# Fichier actions.php — AOW_Actions
**Chemin :** `modules/AOW_Actions/actions.php`
**Type :** PHP
**Dernière mise à jour doc :** 2026-05-31

## Rôle fonctionnel
Registre des types d'actions disponibles dans le workflow. Déclare la liste des actions (SendEmail, ModifyRecord, CalculateFields, CreateRecord, etc.) disponibles dans le sélecteur de l'éditeur.

## Type
config / helper

## Notes
Probablement un tableau `$aow_actions` ou `$actions_list` avec les types d'actions disponibles. Utilisé par l'éditeur pour peupler le sélecteur d'action.
