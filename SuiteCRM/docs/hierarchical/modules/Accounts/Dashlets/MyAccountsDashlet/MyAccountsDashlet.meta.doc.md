**Chemin :** `modules/Accounts/Dashlets/MyAccountsDashlet/MyAccountsDashlet.meta.php`
**Type :** `PHP`
**Categorie :** configuration (metadonnees dashlet)
**Derniere mise a jour doc :** 2026-05-31

---

## Ce que ce fichier configure

Declare les metadonnees du dashlet `MyAccountsDashlet` dans `$dashletMeta` : module source, titre traduit, description et categorie d'affichage.

---

## Parametres cles

| Parametre | Valeur | Effet |
| --- | --- | --- |
| `module` | `Accounts` | Module source des donnees |
| `title` | `LBL_HOMEPAGE_TITLE` (traduit) | Titre affiche dans la liste des dashlets |
| `description` | "A customizable view into Accounts" | Description pour le selecteur de dashlets |
| `category` | `Module Views` | Categorie dans l'interface de selection |

## Impacte par / impacte

- Consomme par le framework dashlet lors de l'enregistrement et de la liste des dashlets disponibles

## Points d'attention

- Fichier de configuration pur. RAS.
