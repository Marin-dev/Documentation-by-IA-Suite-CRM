# Metadata du module FP_events

**Chemin :** `modules/FP_events/metadata/`
**Type :** PHP — configuration (metadata SugarCRM)
**Derniere mise a jour doc :** 2026-06-02

---

## Contenu du dossier
Fichiers de configuration pure pour les vues du module FP_events.

| Fichier | Role |
|---|---|
| `SearchFields.php` | Champs de recherche |
| `additionalDetails.php` | Details additionnels pour la vue liste (popup hover) |
| `dashletviewdefs.php` | Configuration vue dashlet |
| `detailviewdefs.php` | Vue detail (nom, dates, lieu, budget, invites) |
| `editviewdefs.php` | Formulaire d'edition (avec template d'invitation) |
| `listviewdefs.php` | Vue liste |
| `metafiles.php` | Fichiers metadata a charger |
| `popupdefs.php` | Popup de selection |
| `quickcreatedefs.php` | Creation rapide |
| `searchdefs.php` | Filtres |
| `studio.php` | Studio |
| `subpaneldefs.php` | Sous-panneaux (contacts, leads, FP_Event_Locations) |
| `subpanels/default.php` | Sous-panneau par defaut |

## Points d'attention
- `additionalDetails.php` est specifique a FP_events — affiche un resume de l'evenement au survol dans la vue liste.
