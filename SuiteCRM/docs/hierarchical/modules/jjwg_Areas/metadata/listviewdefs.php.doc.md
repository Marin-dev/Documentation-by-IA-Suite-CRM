## Rôle
Definit les colonnes affichees dans la vue liste (ListView) du module jjwg_Areas.

**Type :** config

## Colonnes par defaut

| Colonne | Largeur | Lien |
|---|---|---|
| NAME | 32% | oui |
| CITY | 10% | non |
| STATE | 10% | non |
| COUNTRY | 10% | non |
| ASSIGNED_USER_NAME | 9% | non |

Colonnes masquees par defaut : MODIFIED_BY_NAME, DATE_MODIFIED, DATE_ENTERED, DESCRIPTION, COORDINATES, CREATED_BY_NAME.
