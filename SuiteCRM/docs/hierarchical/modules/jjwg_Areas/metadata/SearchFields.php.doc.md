# SearchFields.php (jjwg_Areas)

**Chemin :** `modules/jjwg_Areas/metadata/SearchFields.php`
**Type :** PHP — configuration de recherche
**Dernière mise à jour doc :** 2026-06-02

---

## Rôle
Definit les champs de recherche disponibles dans la vue liste du module jjwg_Areas.

**Type :** config

---

## Champs de recherche

| Champ | Type requete | Notes |
|---|---|---|
| name | default | Nom de la zone |
| current_user_only | default | Filtre "mes enregistrements" |
| assigned_user_id | default | Filtre par utilisateur assigne |

---

## Notes
- Fichier standard de configuration des filtres de liste.
