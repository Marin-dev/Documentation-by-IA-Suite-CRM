# subpaneldefs.php (jjwg_Areas)

**Chemin :** `modules/jjwg_Areas/metadata/subpaneldefs.php`
**Type :** PHP — configuration de sous-panneaux
**Dernière mise à jour doc :** 2026-06-02

---

## Rôle
Definit le sous-panneau "Maps" (jjwg_Maps) affiche dans la vue detail d'une zone. Permet d'associer des cartes a une zone directement depuis la fiche zone.

**Type :** config

---

## Sous-panneaux configures

| Nom | Module lie | Relation | Boutons |
|---|---|---|---|
| jjwg_maps_jjwg_areas | jjwg_Maps | jjwg_maps_jjwg_areas | Create, MultiSelect |

---

## Notes
- La relation est many-to-many entre jjwg_Maps et jjwg_Areas.
