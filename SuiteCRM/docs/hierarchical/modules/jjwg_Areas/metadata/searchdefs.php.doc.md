# searchdefs.php (jjwg_Areas)

**Chemin :** `modules/jjwg_Areas/metadata/searchdefs.php`
**Type :** PHP — configuration de recherche
**Dernière mise à jour doc :** 2026-06-02

---

## Rôle
Definit la disposition des champs dans les formulaires de recherche basique et avancee de la vue liste jjwg_Areas.

**Type :** config

---

## Notes
- Consomme par le moteur de recherche SuiteCRM pour generer les formulaires de filtre.
- Contenu exact : INCONNU (fichier non lu ; champs presumes : name, city, state, country, assigned_user_id, current_user_only).
