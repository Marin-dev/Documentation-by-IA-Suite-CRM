# EmailTemplateFormBase.php

**Chemin :** `modules/EmailTemplates/EmailTemplateFormBase.php`
**Type :** PHP
**Dernière mise à jour doc :** 2026-05-31

---

## Rôle
Classe de base pour les formulaires de templates email. Fournit `getFormBody()` qui genere le HTML du formulaire de saisie d'un template (sujet, corps, pieces jointes).

**Type :** helper / view helper

---

## Exports / Symboles principaux
| Symbole | Type | Role |
|---|---|---|
| `EmailTemplateFormBase` | classe | Base formulaire template email |
| `getFormBody()` | methode | Genere le HTML du formulaire (prefixe, module, nom, taille) |
