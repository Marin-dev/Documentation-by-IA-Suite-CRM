## Rôle

Fichier de traduction anglais (en_US) du module Contacts. Déclare les tableaux `$mod_strings` et `$mod_list_strings` contenant tous les libellés, titres, messages d'erreur spécifiques au module Contacts.

**Type :** configuration

**Configure :** Traductions anglaises du module Contacts

## Notes

- Chargé via `return_module_language($current_language, 'Contacts')`
- Surchargeable dans `custom/modules/Contacts/language/en_us.lang.php`
- Contient notamment les libellés de champs (nom, prénom, titre, etc.), les messages portail AOP (`LBL_CREATE_PORTAL_USER_*`, `LBL_DISABLE_PORTAL_USER_*`) et les intitulés de l'interface
