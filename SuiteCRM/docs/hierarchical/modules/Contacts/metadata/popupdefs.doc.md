# popupdefs.php

**Chemin :** `modules/Contacts/metadata/popupdefs.php`
**Type :** PHP — configuration / metadata
**Dernière mise à jour doc :** 2026-05-31

---

## Rôle

Définit la configuration de la vue popup standard de sélection de contact. Utilisée depuis d'autres modules pour permettre la sélection d'un contact via une fenêtre popup (relation many-to-many ou champ relate).

**Type :** configuration

**Configure :** Vue popup Contacts (`$popupMeta`)

## Notes

- Chargé via `metafiles.php` → `popupdefs`
- Voir aussi `popupdefsEmail.php` pour la variante dédiée aux emails
