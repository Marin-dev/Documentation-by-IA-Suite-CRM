# editviewdefs.php

**Chemin :** `modules/Contacts/metadata/editviewdefs.php`
**Type :** PHP — configuration / metadata
**Dernière mise à jour doc :** 2026-05-31

---

## Rôle

Définit la structure et les champs du formulaire d'édition (EditView) du module Contacts. Déclare les panneaux, l'ordre des champs et les propriétés d'édition pour la création et la modification d'un contact.

**Type :** configuration

**Configure :** Vue EditView du module Contacts (`$viewdefs['Contacts']['EditView']`)

## Notes

- Chargé via `metafiles.php` → `editviewdefs`
- Peut être surchargé dans `custom/modules/Contacts/metadata/editviewdefs.php`
