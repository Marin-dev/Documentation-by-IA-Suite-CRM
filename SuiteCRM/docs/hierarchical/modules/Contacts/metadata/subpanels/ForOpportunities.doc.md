# ForOpportunities.php

**Chemin :** `modules/Contacts/metadata/subpanels/ForOpportunities.php`
**Type :** PHP — configuration / metadata subpanel
**Dernière mise à jour doc :** 2026-05-31

## Rôle

Définition du sous-panneau Contacts affiché dans la vue détail d'une Opportunité. Configure les colonnes incluant le rôle du contact (`contact_role`) dans l'opportunité via la table `opportunities_contacts`.

**Configure :** Sous-panneau Contacts dans le module Opportunities. Affiche le rôle spécifique du contact.
