## Rôle

Définition du sous-panneau Contacts dans le contexte des événements FP (FP_events). Configure les colonnes et la requête pour lister les contacts liés à un événement via la table de relation `fp_events_contacts`.

**Configure :** Sous-panneau Contacts dans le module FP_Events (événements/inscriptions).

## Notes

- Spécifique au module d'événements `FP_events` — extension SuiteCRM pour la gestion d'événements et inscriptions.
