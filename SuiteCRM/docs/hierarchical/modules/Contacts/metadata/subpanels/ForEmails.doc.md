## Rôle

Définition du sous-panneau Contacts affiché dans la vue détail d'un Email. Configure les colonnes pour lister les contacts destinataires/expéditeurs d'un email via la table `emails_beans`.

**Configure :** Sous-panneau Contacts dans le module Emails.
