## Rôle

Définition du sous-panneau Contacts affiché dans la vue détail d'un Projet. Configure les colonnes pour lister les contacts participants à un projet via la table de relation projet-contacts.

**Configure :** Sous-panneau Contacts dans le module Projects (AM_ProjectTemplates).
