# ForContacts.php

**Chemin :** `modules/Contacts/metadata/subpanels/ForContacts.php`
**Type :** PHP — configuration / metadata subpanel
**Dernière mise à jour doc :** 2026-05-31

## Rôle

Définition du sous-panneau Contacts affiché dans la vue détail d'un autre Contact (relation "Reports To" / contacts liés). Configure les colonnes pour afficher les contacts subordonnés via le champ `reports_to_id`.

**Configure :** Sous-panneau Contacts dans le module Contacts (relation hiérarchique).
