# listviewdefs.php

**Chemin :** `modules/Contacts/metadata/listviewdefs.php`
**Type :** PHP — configuration / metadata
**Dernière mise à jour doc :** 2026-05-31

---

## Rôle

Définit les colonnes et le comportement de la vue liste (ListView) du module Contacts. Déclare les champs affichés en colonnes, leur tri, et les propriétés d'affichage dans la liste des contacts.

**Type :** configuration

**Configure :** Vue ListView du module Contacts (`$listViewDefs['Contacts']`)

## Notes

- Chargé via `metafiles.php` → `listviewdefs`
- Peut être surchargé dans `custom/modules/Contacts/metadata/listviewdefs.php`
