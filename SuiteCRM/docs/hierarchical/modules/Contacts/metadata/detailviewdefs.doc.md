# detailviewdefs.php

**Chemin :** `modules/Contacts/metadata/detailviewdefs.php`
**Type :** PHP — configuration / metadata
**Dernière mise à jour doc :** 2026-05-31

---

## Rôle

Définit la structure et les champs affichés dans la vue détail (DetailView) du module Contacts. Déclare les panneaux, colonnes et champs affichés lors de la consultation d'un contact.

**Type :** configuration

**Configure :** Vue DetailView du module Contacts (`$viewdefs['Contacts']['DetailView']`)

## Notes

- Chargé via `metafiles.php` → `detailviewdefs`
- Peut être surchargé dans `custom/modules/Contacts/metadata/detailviewdefs.php`
