## 🎯 Ce que ce fichier configure
Définit `$mod_strings` et/ou `$app_list_strings` pour le module Calendar en anglais. Contient les libellés d'interface, messages d'erreur, noms de vues (LBL_AGENDADAY, LBL_MONTH, ERR_YEAR_BETWEEN, etc.).
