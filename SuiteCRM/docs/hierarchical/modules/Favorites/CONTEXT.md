## 🎯 Responsabilité fonctionnelle
Le module Favorites gère les enregistrements favoris des utilisateurs. Permet de marquer n'importe quel enregistrement CRM comme favori pour un accès rapide.

## ⚙️ Responsabilité technique
Bean `Favorites` (hérite de `SugarBean`). Table `sugarfavorites` (ou similaire). Module utilitaire.
