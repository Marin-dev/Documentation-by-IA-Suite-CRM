**Type :** PHP — bibliothèque tierce
**Dernière mise à jour doc :** 2026-05-31

## Rôle fonctionnel
Point d'entrée de la bibliothèque pChart. Charge les classes de la bibliothèque : pData, pDraw, pImage, pPie, pRadar, etc. Utilisé par `AOR_Chart::buildChartImage()` pour la génération d'images graphiques PNG.

## Type
autre (bibliothèque tierce)

## Notes
Bibliothèque tierce pChart (http://www.pchart.net). Ne pas modifier. Consommé uniquement par `AOR_Chart`.
