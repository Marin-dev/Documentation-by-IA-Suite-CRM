## Role fonctionnel
Vue de detail d'un rapport AOR. Affiche le rapport execute avec ses resultats, ses graphiques et les options d'export (CSV, PDF). Integre la pagination AJAX et les graphiques RGraph/pChart.

- Contenu INCONNU — fichier non lu directement.
- C'est le point d'entree de la visualisation d'un rapport — contient probablement du JavaScript pour les interactions dynamiques.
