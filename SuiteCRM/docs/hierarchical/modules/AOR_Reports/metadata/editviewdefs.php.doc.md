# Fichier editviewdefs.php

**Chemin :** `modules/AOR_Reports/metadata/editviewdefs.php`
**Type :** PHP — configuration
**Dernière mise à jour doc :** 2026-05-31

---

## Rôle fonctionnel
Définit la mise en page de la vue EditView du module AOR_Reports (formulaire de création/édition d'un rapport).

## Type
config

---

## Notes
Fichier de métadonnées standard SuiteCRM. Déclare `$viewdefs['AOR_Reports']['EditView']`. Inclut probablement les champs `field_lines`, `condition_lines` (function fields) qui déclenchent l'affichage des widgets dynamiques.
