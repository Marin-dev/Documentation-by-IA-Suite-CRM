# AORReportsDashlet.php

**Chemin :** `modules/AOR_Reports/Dashlets/AORReportsDashlet/AORReportsDashlet.php`
**Type :** PHP - Dashlet (widget tableau de bord)
**Derniere mise a jour doc :** 2026-05-31

## Role fonctionnel
Dashlet permettant d'afficher un rapport AOR directement sur le tableau de bord SuiteCRM. L'utilisateur peut configurer quel rapport afficher et les parametres associes.

## Relations cles
- **Appelle :** `AOR_Report->build_group_report()` ou similaire pour afficher les resultats

## Points d'attention
- Contenu INCONNU — fichier non lu directement.
- Le fichier `AORReportsDashlet.meta.php` contient la configuration du dashlet (titre, description, etc.).
