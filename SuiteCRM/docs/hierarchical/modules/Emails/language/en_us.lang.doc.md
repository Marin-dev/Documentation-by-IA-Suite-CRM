# Fichier : en_us.lang.php (configuration)

**Chemin :** `modules/Emails/language/en_us.lang.php`
**Configure :** Chaines de traduction anglais du module Emails
**Derniere mise a jour doc :** 2026-05-31

## Ce que ce fichier configure

Definit `$mod_strings` pour la langue anglaise : labels des champs, messages d'erreur, textes des boutons, messages de statut (LBL_*, ERR_*, LNK_*). Reference par toutes les vues et le controleur du module Emails.

## Parametres cles

INCONNU — contenu non lu (entete seulement visible). Inclut des chaines pour les labels de vues, erreurs de validation expediteur (`ERR_FIELD_FROM_IS_NOT_SET`, etc.) et messages IMAP.

## Impacte par / impacte

- Consomme par toutes les classes du module via `$mod_strings`
- Traduit en d'autres langues via des fichiers `{lang_code}.lang.php` paralleles

## Points d'attention

- Mis a jour en 2024 (SalesAgility) — version la plus recente des chaines.
