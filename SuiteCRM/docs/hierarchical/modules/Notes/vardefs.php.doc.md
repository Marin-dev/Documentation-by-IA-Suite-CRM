## Ce que ce fichier configure
Definition du schema `$dictionary['Note']` pour la table `notes`. Champs specifiques : `filename`, `file_mime_type`, `portal_flag`, `embed_flag`.

## Parametres cles distinctifs
| Parametre | Effet |
|---|---|
| `filename` | nom du fichier attache |
| `file_mime_type` | type MIME du fichier |
| `portal_flag` | visible depuis le portail client |
| `embed_flag` | image inline dans un email |
| `parent_type / parent_id` | module et enregistrement parent |
