## Rôle

Définition du sous-panneau Campaigns pour le contexte EmailMarketing. Configure les colonnes et la requête pour afficher les campagnes associées à un email marketing donné.

**Type :** configuration

**Configure :** Sous-panneau Campaigns dans le module EmailMarketing.

## Notes

- Spécifique à la relation `campaign_email_marketing` (une campagne peut avoir plusieurs emails marketing)
- Référencé dans `subpaneldefs.php` du module EmailMarketing
