# action_view_map.php

**Dernière mise à jour doc :** 2026-06-02

## Rôle

Mappe les actions du module EmailMan vers leurs vues correspondantes. Permet au dispatcher SugarCRM de trouver la vue à charger pour chaque action.

## Type

config

- Aucune

## Exports / Symboles principaux
