# Fichier : en_us.lang.php

**Chemin :** `modules/Surveys/language/en_us.lang.php`
**Type :** PHP — configuration (fichier de langue anglais)
**Derniere mise a jour doc :** 2026-06-02

---

## Ce que ce fichier configure
Chaines de traduction anglaises pour le module Surveys : labels des champs, statuts (`Draft`, `Public`, `Closed`), texte du bouton de soumission, message de remerciement (`LBL_SURVEY_THANKS`), message de fermeture (`LBL_SURVEY_CLOSE_RESPONSE`).

## Points d'attention
- `LBL_SURVEY_THANKS` est utilise par `modules/Surveys/Entry/Thanks.php`.
- `LBL_SURVEY_CLOSE_RESPONSE` est utilise par `modules/Surveys/Entry/Survey.php`.
