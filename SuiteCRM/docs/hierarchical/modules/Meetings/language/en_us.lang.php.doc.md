# Fichier : en_us.lang.php (configuration)

**Chemin :** `modules/Meetings/language/en_us.lang.php`
**Configure :** chaines de traduction anglaises du module Meetings
**Derniere mise a jour doc :** 2026-05-31

## Ce que ce fichier configure
Declare les tableaux `$mod_strings` et eventuellement `$mod_list_strings` avec toutes les labels, titres et messages du module Meetings en anglais americain.

## Points d'attention
Fichier de traduction standard SuiteCRM. Remplace par `custom/modules/Meetings/language/en_us.lang.php` si personnalisation.
