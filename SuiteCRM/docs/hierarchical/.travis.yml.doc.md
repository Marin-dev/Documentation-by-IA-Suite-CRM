# .travis.yml (configuration)

**Chemin :** `.travis.yml`
**Configure :** `Travis CI — pipeline d'intégration continue`
**Dernière mise à jour doc :** 2026-05-30

## Rôle

Fichier de configuration Travis CI définissant le pipeline d'intégration continue de SuiteCRM. Orchestre l'installation, la configuration de l'environnement, et l'exécution des différentes suites de tests.

**Type :** config (CI/CD)

## Ce que ce fichier configure

Définit 3 jobs CI sur PHP 7.4 / Ubuntu Xenial avec MySQL 5.7 et Elasticsearch, incluant l'installation de SuiteCRM, les tests unitaires PHPUnit, les tests API V8, et les tests d'acceptance Codeception.

## Paramètres clés

| Paramètre | Valeur | Effet |
|---|---|---|
| Langage | `php` | Environnement PHP sur Linux |
| PHP version | `7.4` | Version testée (note: décalée vs composer.json qui exige 8.1) |
| OS | `linux` / `xenial` | Ubuntu 16.04 |
| Services | `mysql`, `elasticsearch` | Services requis pour les tests |
| Browser | Chrome stable | Pour les tests d'acceptance |

## Jobs de la matrix

| Job | Description |
|---|---|
| `PHP 7.4 / MySQL 5.7` | Job principal : install + tests unit + API + acceptance |
| `composer validate` | Valide `composer.json` / `composer.lock` |
| `code coverage` | Génère et uploade la couverture vers Codecov |

## Variables d'environnement injectées

| Variable | Valeur |
|---|---|
| `INSTANCE_URL` | `http://localhost` |
| `DATABASE_DRIVER` | `MYSQL` |
| `DATABASE_NAME` | `automated_tests` |
| `DATABASE_HOST` | `localhost` |
| `DATABASE_USER` / `PASSWORD` | `automated_tests` |
| `INSTANCE_ADMIN_USER` | `admin` |
| `INSTANCE_ADMIN_PASSWORD` | `admin1` |

## Étapes du pipeline

1. **before_install** : Installation ChromeDriver, lint PHP des fichiers modifiés
2. **install** : Configuration PHP, `composer install`, `codecept build`
3. **before_script** : Création base MySQL, installation Apache + PHP-FPM, config vhost
4. **script** : Installation SuiteCRM via wizard → PHPUnit → OAuth2 keys → API tests → Acceptance tests
5. **after_script** : Publication des sorties, logs Elasticsearch et Apache

## Branches ciblées

`master`, `develop`, `hotfix/*`, `feature/*`, `fix/*`, `staging/*`

## Impacté par / impacte

- Consomme `.env.dist` / `.env.test` via les variables d'environnement
- Lance `codeception.dist.yml` pour les suites de tests
- Génère `tests/_output/coverage.xml` uploadé vers Codecov

## Points d'attention

- **PHP 7.4 dans Travis vs PHP 8.1 requis dans `composer.json`** — décalage significatif, Travis CI est probablement obsolète.
- Travis CI est un service payant depuis 2021 pour les projets open source — ce fichier peut ne plus être actif (GitHub Actions est l'alternative probable).
- Les clés OAuth2 sont générées dans le CI (`openssl genrsa`) avec permissions `600`.
- `travis.php.ini` est référencé mais non présent dans la liste des fichiers documentés.
