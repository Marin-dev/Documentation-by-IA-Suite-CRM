# Activities

## Rôle
Tests d'acceptation du module Activities (activités) de SuiteCRM. Vérifie les fonctionnalités de suivi des activités liées aux contacts, comptes et opportunités (appels, réunions, tâches).

## Contenu
| Fichier | Rôle |
|---|---|
| `ActivitiesCest.php` | Scénarios d'acceptation pour le module Activities |

## Points d'entrée
- `ActivitiesCest` — suite de tests du module

## Dépendances clés
- Dépend de : `AcceptanceTester`, `_support/Step/Acceptance/`
- Utilisé par : pipeline CI/CD

## Notes
Couvre les activités liées aux modules Calls, Meetings et Tasks.
