# Tasks

## Rôle
Tests d'acceptation du module Tasks (tâches) de SuiteCRM. Vérifie la création, l'affectation et le suivi des tâches associées aux contacts, comptes et opportunités.

## Contenu
| Fichier | Rôle |
|---|---|
| `TasksCest.php` | Scénarios d'acceptation pour le module Tasks |

## Points d'entrée
- `TasksCest` — suite de tests du module

## Dépendances clés
- Dépend de : `AcceptanceTester`, `_support/Step/Acceptance/`
- Utilisé par : pipeline CI/CD

## Notes
Module activité — apparaît dans les sous-panneaux Activities de la plupart des modules.
