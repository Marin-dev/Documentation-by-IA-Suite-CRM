# Leads

## Rôle
Tests d'acceptation du module Leads (prospects) de SuiteCRM. Vérifie la création, la qualification et la conversion des leads en contacts/comptes/opportunités.

## Contenu
| Fichier | Rôle |
|---|---|
| `LeadsCest.php` | Scénarios d'acceptation pour le module Leads |

## Points d'entrée
- `LeadsCest` — suite de tests du module

## Dépendances clés
- Dépend de : `AcceptanceTester`, `_support/Step/Acceptance/`
- Utilisé par : pipeline CI/CD

## Notes
Module clé du processus de conversion prospect → client dans SuiteCRM.
