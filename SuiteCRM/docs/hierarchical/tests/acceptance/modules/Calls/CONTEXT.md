# Calls

## Rôle
Tests d'acceptation du module Calls (appels) de SuiteCRM. Vérifie la création, la planification et le suivi des appels téléphoniques, ainsi que les relations avec les contacts et comptes.

## Contenu
| Fichier | Rôle |
|---|---|
| `CallsCest.php` | Scénarios d'acceptation pour le module Calls |

## Points d'entrée
- `CallsCest` — suite de tests du module

## Dépendances clés
- Dépend de : `AcceptanceTester`, `_support/Step/Acceptance/Calls.php`
- Utilisé par : pipeline CI/CD

## Notes
Module core des activités CRM — relations avec Contacts, Accounts, Leads.
