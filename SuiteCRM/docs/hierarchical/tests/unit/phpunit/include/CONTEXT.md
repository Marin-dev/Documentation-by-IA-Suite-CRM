# include

## Rôle
Tests unitaires PHPUnit pour les composants de l'espace `include/` de SuiteCRM. Organisé par module — chaque sous-dossier correspond au module testé.

## Contenu
| Dossier | Rôle |
|---|---|
| `CalendarSync/` | Tests unitaires du module CalendarSync |

## Points d'entrée
Chaque sous-dossier contient ses propres classes de test.

## Dépendances clés
- Dépend de : `SuiteCRM/Test/`, modules correspondants dans `include/`
- Utilisé par : pipeline CI/CD (suite unit)

## Notes
Structure miroir de `include/` — à compléter au fur et à mesure des couvertures de test.
