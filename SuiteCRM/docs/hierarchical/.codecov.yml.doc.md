# .codecov.yml (configuration)

**Chemin :** `.codecov.yml`
**Configure :** `Codecov — service de couverture de code`
**Dernière mise à jour doc :** 2026-05-30

## Rôle

Fichier de configuration du service Codecov pour SuiteCRM. Définit les seuils de couverture, les comportements de notification, et les chemins exclus de l'analyse de couverture.

**Type :** config (CI/CD)

## Ce que ce fichier configure

Configure le rapport de couverture de code envoyé à Codecov après chaque run CI. Définit la précision (2 décimales), la plage acceptable (70-100%), et les chemins de bibliothèques tierces exclus de l'analyse.

## Paramètres clés

| Paramètre | Valeur | Effet |
|---|---|---|
| `require_ci_to_pass` | `yes` | Le CI doit passer pour que Codecov notifie |
| `precision` | `2` | 2 décimales dans les rapports |
| `round` | `down` | Arrondi vers le bas |
| `range` | `70...100` | Plage de couverture acceptable (70% = seuil bas, 100% = idéal) |
| `target` | `0%` | Cible minimale projet = 0% (non bloquant) |
| `threshold` | `5%` | Tolérance de baisse avant échec = 5% |
| `patch` | `no` | Pas d'analyse de couverture sur les patches |
| `changes` | `no` | Pas d'analyse sur les changements isolés |

## Impacté par / impacte

- Alimenté par les rapports de couverture générés par Codeception (`.travis.yml` ligne 19 : `coverage.xml`)
- Présente les résultats sur `codecov.io` avec commentaires sur les PRs

## Points d'attention

- `target: 0%` signifie qu'aucun seuil de couverture minimal n'est imposé — la couverture actuelle est probablement faible.
- `lib/API/.*` (API V8 en minuscules) est explicitement exclu car dépréciée/non testée en CI.
